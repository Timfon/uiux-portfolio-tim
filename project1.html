Redesigning the Dwarf Fortress Website

UX/UI redesign for the Dwarf Fortress Website

Context & Problem

I chose this website because it's a little hard to tell what links I should be clicking, where I should go to download the game, and overall it's a lot of information to process at once.

Efficiency

All the information on where you want to go is easily accessible on the navigation menu at the top.

There are multiple download buttons, making it easier for users to navigate.

Learnability

No search functionality, can be hard to navigate with the amount of ascii visual background noise.

Navigation options aren’t grouped by functionality, so it can be difficult for new users to find all the information they would need.

Memorability

The retro theme and the ascii background art makes the website very memorable and matches the game’s retro aesthetic.

The chronological order of the update timeline makes it easy for users to identify the latest patch notes.

Conceptual Model

It can be initially hard to tell what this website is doing. Is it trying to get you to download the game? Is it just a place for dev logs? There could be potential confusion there.

The version number helps indicate how long development has been going on for, and gives users an idea of the kind of game they’re getting into.

WebAIM WAVE

Some linked images missing alternative text.

Lots of redundant title text.

However, the website does have 170/182 features that have an alternative text.

No contrast errors were detected, but I disagree with that. It can be hard to tell what you’re looking at initially.

Conclusions

  • Simplifying the UI for new users, and making the download button as easily accessible as possible are very important when promoting a game.
  • Grouping navigation links by functionality improves learnability and helps users quickly locate the resources they need.
  • Maintaining the retro aesthetic is important for memorability and staying true to the identity of Dwarf Fortress, but it should not come at the cost of usability.
